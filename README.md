**TypeDash**

A quiet typing app built with React, TypeScript, and Vite. No login, API keys, database, or application server.

Phase 1 provides a responsive, explicitly labeled practice preview. The sample-refresh button and About dialog work. Typing, timing, results, and persistence will be implemented in later approved phases; see [PLAN.md](./PLAN.md).

**Run locally**

Use Node.js 24 and npm. Install dependencies with `npm ci`, then run `npm run dev`. Open the Local URL printed by Vite.

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start local development. |
| `npm run lint` | Check source and tooling with ESLint. |
| `npm run typecheck` | Check application, fixtures, and test types. |
| `npm test` | Validate the scoring fixtures' arithmetic. Phase 2 adds engine replay tests. |
| `npm run build` | Type-check, produce `dist/`, and enforce initial asset budgets. |
| `npm run preview` | Preview the production build locally. |
| `npm run test:e2e` | Run shell browser tests against the production build. |
| `npm run check` | Run lint, types, fixture checks, and the production build. |

For standalone browser tests, first run `npm run build` and `npx playwright install chromium firefox webkit`, then `npm run test:e2e`. Playwright starts the local production preview automatically. Browser downloads are only needed for development tests.

The phase 1 behavior contract is in [docs/behavior.md](./docs/behavior.md). Human-authored scoring fixtures are in `tests/fixtures/scoring.ts`; they are a specification, not an implemented engine. Build-size reporting is generated by `scripts/check-bundle.mjs`.

**Deployment target**

Vercel preset: Vite. Install: `npm ci`. Build: `npm run build`. Output: `dist`. No environment variables are required. Publishing is reserved for a separately authorized release step.

**Assets**

Roboto Mono regular Latin is bundled through Fontsource and served locally. The font license and attribution are retained in `public/licenses/`. TypeDash's wordmark, favicon, and interface icons are original SVGs. Preview sentences are authored for this project; the first-release word dataset will be introduced with the typing engine.
