**TypeDash**

A quiet typing app built with React, TypeScript, and Vite. No login, API keys, database, or application server.

Phase 2 provides a working 30-second English typing test: start on the first key, see character feedback, edit mistakes, review WPM/raw speed/accuracy, and restart or retry the same text. More test modes, detailed results, and local progress will be implemented in later approved phases; see [PLAN.md](./PLAN.md).

Validation and browser screenshots are recorded in [the phase 2 handoff](./docs/phase-2.md).

**Run locally**

Use Node.js 24 and npm. Install dependencies with `npm ci`, then run `npm run dev`. Open the Local URL printed by Vite.

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start local development. |
| `npm run lint` | Check source and tooling with ESLint. |
| `npm run typecheck` | Check application, fixtures, and test types. |
| `npm test` | Replay scoring fixtures and test editing, timing, generation, and native input handling. |
| `npm run build` | Type-check, produce `dist/`, and enforce initial asset budgets. |
| `npm run preview` | Preview the production build locally. |
| `npm run test:e2e` | Run shell and complete typing flows against the production build. |
| `npm run check` | Run lint, types, engine/input/clock tests, and the production build. |

For standalone browser tests, first run `npm run build` and `npx playwright install chromium firefox webkit`, then `npm run test:e2e`. Playwright starts the local production preview automatically. Browser downloads are only needed for development tests.

The behavior contract is in [docs/behavior.md](./docs/behavior.md). Human-authored scoring fixtures in `tests/fixtures/scoring.ts` are replayed against the engine by `tests/unit/engine.test.ts`. Build-size reporting is generated by `scripts/check-bundle.mjs`.

**Deployment target**

Vercel preset: Vite. Install: `npm ci`. Build: `npm run build`. Output: `dist`. No environment variables are required. Publishing is reserved for a separately authorized release step.

**Assets**

Roboto Mono regular Latin is bundled through Fontsource and served locally. The font license and attribution are retained in `public/licenses/`. TypeDash's wordmark, favicon, and interface icons are original SVGs. The English practice list is independently assembled for this project in `src/data/english.ts`.
