**TypeDash**

A quiet typing app built with React, TypeScript, and Vite. No login, API keys, database, or application server.

TypeDash includes time and word tests, punctuation and numbers, immediate character feedback, focus recovery, detailed results and graphs, local history, and personal bests. Settings includes light/dark themes, font sizes, smooth caret, reduced motion, and optional live statistics. Phase 6 adds release tooling, Vercel configuration, and performance checks; remaining validation is tracked in [PLAN.md](./PLAN.md).

On a first visit, the default is a 30-second English test and word mode initially selects 25 words. The last settings and both modes' lengths survive reload. Changing the mode, length, punctuation, or numbers starts a fresh test. Appearance changes keep the active test and its text. Focus loss blurs the prompt and shows a recovery control; active tests keep counting elapsed time.

Open Settings for dark or light themes, 22/28/34 px typing text, caret animation, reduced motion, live WPM, and live accuracy. Defaults are dark, 28 px, smooth caret, and hidden live statistics. System reduced motion always takes precedence. Live statistics refresh at most ten times per second, without repeated screen-reader announcements. Native dialogs support Escape and keyboard focus restoration.

Open History to inspect recent results and their graphs, or view personal bests. Fresh tests and same-text retries have separate best scores. Data stays in this browser; clearing browser data removes it. If saving is blocked or full, the app keeps working in memory and labels new results as kept for the current visit.

Validation and browser screenshots are recorded in [the phase 6 report](./docs/phase-6.md). Deployment and profiling instructions are in [the release guide](./docs/release.md).

**Run locally**

Use Node.js 24 and npm. Install dependencies with `npm ci`, then run `npm run dev`. Open the Local URL printed by Vite.

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start local development. |
| `npm run lint` | Check source and tooling with ESLint. |
| `npm run typecheck` | Check application, fixtures, and test types. |
| `npm test` | Test scoring, modes, input, timing, sampling, storage/migration, prompt geometry, and theme contrast. |
| `npm run build` | Type-check, produce `dist/`, enforce asset budgets, and check the release artifact/configuration. |
| `npm run preview` | Preview the production build locally. |
| `npm run test:e2e` | Run shell, typing, modes, charts, persistence, appearance, and keyboard flows against the production build. |
| `npm run check` | Run lint, types, engine/input/clock tests, and the production build. |
| `npm run smoke` | Start a temporary production preview, fetch the document and every built asset, then stop it. |
| `npm run benchmark:engine` | Record reducer-only insertion/restart timings in `performance-results/engine.json`. |
| `npm run test:performance` | Record five throttled cold loads, interaction samples, listener counts, and a Chromium presentation trace. |
| `npm run analyze:trace` | Summarize the diagnostic trace and extract sample screenshots. |
| `npm run check:release` | Run all automated checks, including cross-browser and performance suites. Requires installed test browsers. |

For standalone browser tests, first run `npm run build` and `npx playwright install chromium firefox webkit`, then `npm run test:e2e`. Playwright starts the local production preview automatically. Browser downloads are only needed for development tests.

The November 4 validation passed all 114 unit tests and 57 browser cases. Loading, processing, and restart budgets passed. The 32 ms keyboard presentation gate remains open: headed runs reported rounded p95 values of 40–48 ms; `test:performance` and `check:release` enforce the target and currently fail it on this host. See the measured evidence and native-textarea comparison in [docs/phase-6.md](./docs/phase-6.md). The project has not been deployed.

The behavior contract is in [docs/behavior.md](./docs/behavior.md). Human-authored scoring fixtures in `tests/fixtures/scoring.ts` are replayed against the engine by `tests/unit/engine.test.ts`. Build-size reporting is generated by `scripts/check-bundle.mjs`.

Local storage uses `typedash.preferences` with a version-2 envelope and `typedash.progress` with a version-1 envelope. Earlier version-1 preferences migrate automatically, preserving test settings, history, and bests. Preferences load at startup; history loads only when opening it or completing a test. Result serialization runs after the result view paints, with pending work flushed before leaving the page. Chart, history, and settings panels load separately from the typing screen. The storage validation layer retains valid records, recovers malformed data, and preserves unknown newer schemas without overwriting them.

**Deployment target**

The checked-in `vercel.json` selects Vite, `npm ci`, `npm run build`, and `dist`. Hashed assets cache for one year; the root HTML revalidates. This app uses one root document and hash links, so it does not need a catch-all rewrite. No environment variables are required. Follow [docs/release.md](./docs/release.md) and obtain explicit publishing approval before deployment.

**Assets**

Roboto Mono regular Latin is bundled through Fontsource as one preloaded WOFF2 file and served locally. The font license and attribution are retained in `public/licenses/`. TypeDash's wordmark, favicon, and interface icons are original SVGs. The English practice list is independently assembled for this project in `src/data/english.ts`.
