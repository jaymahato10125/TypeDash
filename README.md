**TypeDash**

A quiet typing app built with React, TypeScript, and Vite. No login, API keys, database, or application server.

Phase 4 provides time and word tests, punctuation and number options, character feedback, focus recovery, a speed graph, detailed character counts, saved settings, the latest 100 local results, and personal bests. Restart preserves settings, and same-text retry reproduces the prompt. Theme controls and release validation remain in later approved phases; see [PLAN.md](./PLAN.md).

On a first visit, the default is a 30-second English test and word mode initially selects 25 words. The last settings and both modes' lengths survive reload. Changing a setting starts a fresh test. Focus loss blurs the prompt and shows a recovery control; active tests keep counting elapsed time.

Open History to inspect recent results and their graphs, or view personal bests. Fresh tests and same-text retries have separate best scores. Data stays in this browser; clearing browser data removes it. If saving is blocked or full, the app keeps working in memory and labels new results as kept for the current visit.

Validation and browser screenshots are recorded in [the phase 4 handoff](./docs/phase-4.md).

**Run locally**

Use Node.js 24 and npm. Install dependencies with `npm ci`, then run `npm run dev`. Open the Local URL printed by Vite.

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start local development. |
| `npm run lint` | Check source and tooling with ESLint. |
| `npm run typecheck` | Check application, fixtures, and test types. |
| `npm test` | Test scoring, modes, input, timing, timeline sampling, and local persistence/recovery. |
| `npm run build` | Type-check, produce `dist/`, and enforce initial asset budgets. |
| `npm run preview` | Preview the production build locally. |
| `npm run test:e2e` | Run shell, typing, mode, chart, and persistence flows against the production build. |
| `npm run check` | Run lint, types, engine/input/clock tests, and the production build. |

For standalone browser tests, first run `npm run build` and `npx playwright install chromium firefox webkit`, then `npm run test:e2e`. Playwright starts the local production preview automatically. Browser downloads are only needed for development tests.

The behavior contract is in [docs/behavior.md](./docs/behavior.md). Human-authored scoring fixtures in `tests/fixtures/scoring.ts` are replayed against the engine by `tests/unit/engine.test.ts`. Build-size reporting is generated by `scripts/check-bundle.mjs`.

Local storage uses `typedash.preferences` and `typedash.progress`, each with a version-1 envelope. Preferences load at startup; history loads only when opening it or completing a test. Result serialization runs after the result view paints, with pending work flushed before leaving the page. Chart and history modules load separately from the typing screen. The storage validation layer retains valid records, recovers malformed data, and preserves unknown newer schemas without overwriting them.

**Deployment target**

Vercel preset: Vite. Install: `npm ci`. Build: `npm run build`. Output: `dist`. No environment variables are required. Publishing is reserved for a separately authorized release step.

**Assets**

Roboto Mono regular Latin is bundled through Fontsource and served locally. The font license and attribution are retained in `public/licenses/`. TypeDash's wordmark, favicon, and interface icons are original SVGs. The English practice list is independently assembled for this project in `src/data/english.ts`.
